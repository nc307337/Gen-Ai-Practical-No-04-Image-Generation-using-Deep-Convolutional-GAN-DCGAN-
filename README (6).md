# DCGAN Image Generation – Anime Face Dataset

## Project Overview
This project uses a **Deep Convolutional Generative Adversarial Network (DCGAN)** to generate synthetic anime-face images. The model is trained on a folder of real anime-face images and produces new 32 × 32 RGB images.

The project contains two neural networks:

- **Generator:** Takes a random latent vector and creates a synthetic image.
- **Discriminator:** Classifies an image as real (from the dataset) or fake (generated by the Generator).

The Generator and Discriminator are trained together in an adversarial process.

## Objectives
- Load anime-face images from a local dataset folder.
- Resize images to 32 × 32 pixels and normalize pixel values to the range [-1, 1].
- Build the Generator and Discriminator using TensorFlow/Keras.
- Train the DCGAN and monitor Generator and Discriminator losses.
- Generate and display synthetic anime-face images.
- Save trained models and generated image samples.

## Dataset Setup

1. Download or prepare a dataset containing anime-face images.
2. Extract the images into a folder. For example:

```text
D:/datasets/anime_data/
    image1.jpg
    image2.jpg
    image3.png
    ...
```

3. Open the notebook and set `DATA_DIR` to the actual dataset folder.

Example for Windows:

```python
DATA_DIR = r"D:\datasets\anime_data"
```

Example for Google Colab:

```python
DATA_DIR = "/content/anime_data"
```

The notebook supports `.jpg`, `.jpeg`, `.png`, `.webp`, and `.bmp` images. If using an archive, set `ARCHIVE_PATH` to its exact path and run the extraction cell.

## How to Run

1. Clone or download this project.
2. Place the anime-face images in your dataset folder.
3. Install the required libraries.
4. Open the notebook:

```bash
jupyter notebook
```

5. Open `DCGAN Image Generation — Anime Face Dataset.ipynb`.
6. Update `DATA_DIR` (and `ARCHIVE_PATH` if needed).
7. Run the notebook cells in order:
   - Import libraries and configure paths.
   - Extract the dataset if required.
   - Find and load the images.
   - Preview the real images.
   - Build the Discriminator and Generator.
   - Combine both networks into the GAN.
   - Train the model.
   - Generate sample anime-face images.
   - Save the trained models.

## Model Configuration

| Parameter | Value |
|---|---:|
| Image size | 32 × 32 pixels |
| Image channels | 3 (RGB) |
| Latent dimension | 100 |
| Batch size | 64 |
| Number of epochs | 20 |
| Discriminator learning rate | 0.0002 |
| Generator learning rate | 0.0002 |
| Optimizer | Adam |
| Loss function | Binary cross-entropy |
| Generator output activation | tanh |
| Discriminator output activation | sigmoid |

You can reduce `BATCH_SIZE` (for example, to 16) if your system runs out of memory. You can change `EPOCHS` to train for more or fewer epochs.

The notebook also displays a grid of 25 generated images after training.

## How It Works

1. A random vector of length 100 is supplied to the Generator.
2. The Generator upsamples the vector into a 32 × 32 RGB image.
3. The Discriminator receives real dataset images and generated images.
4. The Discriminator learns to distinguish real images from fake images.
5. The Generator learns to create images that can fool the Discriminator.
6. This process repeats over the configured training epochs.

## Notes and Limitations
- The notebook uses **anime-face images**, not CIFAR-10. The introductory notebook text mentions CIFAR-10, but the implemented data-loading pipeline reads images from `DATA_DIR`; configure that folder with the anime-face dataset.
- Images are resized to 32 × 32, so fine facial details may be limited.
- GAN losses may fluctuate and do not necessarily decrease smoothly.
- Image quality depends on dataset size, image quality, training time, and available hardware.
- Training for 20 epochs is a starting configuration; it does not guarantee high-quality results.
- The notebook does not report a formal image-quality metric such as FID. Its evaluation is based on losses, discriminator accuracy, and visual inspection.
